# Recruweb Design Consistency Update

Updated the Pricing, Candidate Interview Tasks, and Admin Project & Task Assignment screens to use the existing Recruweb Home visual language.

- Global Recruweb font tokens (`--font-heading`, `--font-body`) are used instead of page-specific font families.
- Heading/body sizing follows the Home page hierarchy.
- Cards, spacing, rounded corners, gradients, shadows, and hover treatment follow the Home page style.
- No separate public navbar/footer was introduced.
- Existing functionality and routes were preserved.
