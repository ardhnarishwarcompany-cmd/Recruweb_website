# Recruweb Typography Update

All public pages and the newly added Pricing / Interview Tasks / Project Task Assignment surfaces now use the same Calibri-based corporate typography system as the main Recruweb site.

- Heading and body variables both use Calibri with Segoe UI/Arial fallbacks.
- Removed dependency on Space Grotesk / DM Sans Google Fonts.
- Normalized heading scale, line-height, letter spacing and body readability.
- Removed Plus Jakarta Sans from page-specific inline styles.
- Pricing typography was enlarged and aligned with the main-site visual language.
- Candidate/Admin task pages inherit the same typography system.
